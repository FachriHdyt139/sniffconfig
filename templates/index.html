Frequently Asked (versi sobris) ❓

  
Format apa aja yang didukung?
.HC (HTTP Custom), .EHI (HTTP Injector), .SSC (SSC Custom), .NPV / .NPVT (NPV Tunnel), dan .DARK / darktunnel:// (Dark Tunnel). Ekstensi cuma petunjuk — kalau salah nama file, mesin tetap nyoba semua format.

  
Apakah fileku aman?
File cuma diproses di memori server lalu dibuang — nggak disimpan, nggak dilog, nggak dikirim ke mana-mana. Statistik hanya menghitung jumlah, bukan isinya.

  
Kenapa ada config yang gagal di-sniff?
Beberapa config pakai proteksi HWID/password atau versi enkripsi yang lebih baru dari database key kami. Kalau gagal, chat @BleackCoderr buat request dukungan format.

  
Bisa dipakai buat apa?
Buat audit config sendiri, belajar struktur payload, konversi antar-aplikasi, atau sekadar penasaran isinya apa. Gunakan secara bijak & bertanggung jawab.
